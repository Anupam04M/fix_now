7. FIX STICKY STACKED CARDS ON /service (required for the
   "pages sliding one over the other" scroll effect to work)
   File: src/app/(customerpanel)/layout.tsx
---------------------------------------------------------------
The service page cards use position: sticky. Any ancestor with
overflow-x: hidden becomes a scroll container and silently kills
position: sticky (the cards then scroll away normally instead of
stacking). The layout wrapper div on line 8 currently has
overflow-x-hidden:

   <div className="min-h-screen flex flex-col w-full overflow-x-hidden">

Change it to overflow-x-clip:

   <div className="min-h-screen flex flex-col w-full overflow-x-clip">

overflow-x-clip clips overflow the same way but does NOT create a
scroll container, so position: sticky keeps working. The service
page main element was already changed to overflow-x-clip.

NOTE: body { overflow-x: hidden } in globals.css is fine — it
propagates to the viewport, so it does not affect sticky.
